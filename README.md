## 功能概览

### 一、声音库筛选与试听

在 HeyGen 页面侧边注入一个完整的声音管理面板，支持多维度实时筛选 HeyGen 公共声音库。

**筛选条件**

| 筛选项 | 说明 |
|--------|------|
| 语言 | 按主语言筛选（English / Chinese 等） |
| 地区 | 按口音/地区筛选，英语系地区自动置顶，默认美式英语（en-US） |
| 性别 | 男声 / 女声 |
| 年龄 | 儿童 / 青少年 / 成年 / 中年 / 老年（同义词自动合并） |
| 属性标签 | 多选芯片面板，支持同时选择多个标签（AND 逻辑：声音必须同时具备所有选中标签） |

**标签面板特性**
- 所有同义英文标签（如 podcast / podcasts / podcast hosting）自动合并为一个中文标签（播客）
- 标签面板实时标注可用性：当前筛选条件下无匹配结果的标签自动变灰
- 性别标签不在面板中重复展示（已有独立下拉框）

**声音列表**
- 实时搜索（名称关键词）
- 列内试听：点击播放按钮，直接在页面内试听 30 秒示例音频
- 同步状态标注：标注声音是否已同步到本地数据库、是否缺失
- 一键拉取：将筛选范围内的声音同步到本地

### 二、我的声音（My Voices）

管理账号下已克隆 / 已生成的自定义声音。

**功能**
- 自动分页加载全部自定义声音列表
- **试听**：点击播放按钮，实时通过 HeyGen 流式接口生成预览音频（加载中有旋转动画，约 3–5 秒）
- **单条下载**：点击 ⬇ 按钮，将该声音生成为 MP3 并下载到本地
- **多选批量下载**：
  - 每行左侧勾选框，可勾选任意多条
  - 勾选后顶部出现「下载已选 (N)」按钮，仅下载已勾选声音
  - 「全部下载」按钮：无勾选时下载全部，有勾选时等同于「下载已选」
- **多选批量删除**：
  - 勾选后顶部出现红色「🗑 删除选中 (N)」按钮
  - **仅删除你自己创建的声音**（`creator === 当前账号`）；选中的「他人分享给你的」声音会自动跳过并在确认框内提示
  - 删除前弹出强二次确认，列出将删除的声音名称与数量，明确「不可逆」
  - 逐个执行、每次间隔 1.5–3 秒随机延迟（防风控），执行中按钮变「■ 停止」可随时中断
- 刷新列表时自动清除勾选状态

> 音频通过 `POST /v2/online/voice.stream_preview` 流式接口生成，绕开 CORS 限制，无需额外权限或代理。删除通过 `POST /v1/pacific/voice.delete` 按精确 `voice_id` 执行。

### 三、提示词生成声音（Voice Design）

通过自然语言描述生成全新声音。

- 输入中文或英文提示词，描述目标声音的年龄、性别、口音、情绪、风格等特征
- 系统生成多个候选声音供对比试听
- 满意后一键保存到 HeyGen 账号，自动出现在「我的声音」列表

### 四、AI Studio 快速换声音

在 AI Studio（`/create-v4/`）和 Avatar Shots（`/avatar/avatar-shots`）中，无需手动打开 Switch 弹窗，直接通过插件面板搜索并切换当前场景的声音。

**使用方式**
- 在插件浮窗中切换到「AI Studio 换声音」标签
- 输入 Voice ID 或搜索声音名称，点击对应行即自动切换
- 切换后面板显示 ✅ 结果，AI Studio 右侧面板同步更新

**技术特性**
- 通过 MAIN world 内容脚本（`ais-bridge.js`）读取 React Fiber，直接调用页面内部 `onSelect` 回调，完全绕过 UI 操作
- **绕过「See More」分页限制**：预先通过 API 拉取全量「我的声音」缓存，切换时无论目标声音是否渲染在弹窗内，均可直接命中
- **AI Studio**：自动处理 Avatar & Voice → Edit Voice → Switch 的导航链路，打开面板即可直接使用
- **Avatar Shots**：自动完成 Voice 按钮 → Switch → 选择 → Save changes 的完整流程
- **多语言无关定位**：识别页面「切换 / 确认」按钮、弹窗、标签页时不依赖界面语言文字，改用图标 sprite id、`role="tab"`、主按钮样式等语言无关锚点（文字仅作兜底），英文 / 简体 / 繁体界面均可正常换声音

### 五、分享到期清理

入口在「我的声音」面板的「⏰ 到期清理」按钮。用于自动发现并撤销「分享给其他账号已超过设定天数」的声音权限，避免长期忘记回收。

**使用方式**
- 设定过期天数（默认 60 天，可手动配置）
- 点击重新扫描，列出所有超过天数的分享（声音 × 接收邮箱）
- 勾选后「撤销选中」，或一键「撤销全部超期」
- **白名单**：加入白名单的邮箱永不被列为超期、不会被撤销
- **自动清理开关**（可选，默认关闭）：用户主动勾选后，插件会在后台定时（最短 30 分钟一次）自动撤销达到过期天数的分享

**计时机制（重要局限）**
- HeyGen 的 ACL / `voice.list` 接口**不返回分享创建时间**，因此插件用浏览器 `localStorage` 台账（`hvt_share_ledger_v1`）记录每个分享「首次被扫描到」的时间来估算时长
- **启用功能前已存在的存量分享，一律按启用当天算起**——这是 API 无时间戳导致的固有局限，并非 bug
- 清缓存或更换设备会重置计时（属预期行为）

**安全约束**
- 扫描只处理 `creator === 当前账号` 创建的声音（他人分享给你的声音你无权撤销）
- 撤销通过 `POST /v1/share_resources/remove`，附 4–8 秒随机延迟与停止机制（防风控）

### 六、找我的视频

用于解决团队空间里「自己创建的视频被别人移动到其他文件夹后找不到」的问题。

**功能**
- 悬浮按钮组里的文件夹搜索图标打开「找我的视频」
- 自动快速扫描当前团队空间的根目录和全部文件夹（每夹前 2 页，速度优先）
- 按当前登录账号的 `username` 过滤，只列出你创建的视频
- 可按 `3天前 / 7天前 / 15天前 / 自定义天数` 筛选老视频，方便定位后清理
- 每条显示视频名称、缩略图、创建时间、状态、当前所在文件夹
- 点击「下载」可下载 HeyGen 已返回下载链接的视频，文件保存到下载目录的 `HeyGenVideos/`
- 点击「打开文件夹」跳转到该视频当前所在文件夹
- 本地记录上次扫描的位置；下次扫描发现同一视频换了文件夹，会标记「位置变更」

**说明**
- 当前版本只做定位、下载和位置变更提示，不执行移动/删除操作
- HeyGen 暂未确认视频移动接口，因此「一键移回」暂不包含在本功能内
- 删除老视频请先通过「打开文件夹」定位后在 HeyGen 页面内操作；插件内批量删除需要先确认 HeyGen 的删除/回收站接口，避免误删团队视频

### 七、批量流水线（免 UI 提交视频）

不打开 HeyGen 编辑器，直接通过 API 批量做视频：每个任务 = 一张图片 + 一条文案 + 声音 ID，从提交到下载全程无需人工操作界面。**整批共建 1 个头像组**，每张图作为组内一个「造型（look）」，先统一过审核、只把通过的送去出片。

**功能**
- 悬浮按钮组里的影片图标打开「批量流水线」面板
- **走 Avatar Shots 通道**：Avatar III + 无限模式，不占用月度生成秒数额度（平台另有每日生成上限）
- **默认参数**：Space、**组名**（整批共用，留空自动「批量-日期」）、默认声音 ID、画幅（竖屏 9:16 / 横屏 16:9）、分辨率（720p / 1080p）、Avatar III 开关
- **两阶段流水线**：① 预审——整批建 1 个组、逐张追加为 look、统一等平台构建/审核；② 渲染——只对**审核通过**的 look 按其 `look_id` 出片。审核不通过 / 被平台拒的造型直接标失败、**不进渲染队列**，且不影响其余任务
- **运行日志**：面板底部实时滚动记录（预审 / 上传 / 审核 / 渲染 / 下载 + 具体报错），可一键**下载日志**为 txt 便于排查
- **批量添加任务**：一次选多张图片（原图上传）+ 粘贴等量文案，自动一一配对；选图后有序号预览条。支持配套「口播工具 / AvatarReelsHelper」（<https://avatar-reels-helper-76842936864.us-west1.run.app/>，需访问码）导出的 `copy.tsv`（`#N#` 与图片文件名前导编号精确配对，自动带 `voice_id`），也支持谷歌表格整行/空行分段/每行一条（按文件名排序后顺序配对）
- 文案支持**谷歌表格整行粘贴**：每行一条，两列时第 1 列作标题、第 2 列作文案；也支持空行分段 / 每行一条
- 任务列表显示头像缩略图；**⇅ 调换按钮**可把文案与相邻行对调（图片不动），修正配对错位
- **串行提交**：随机间隔（区间设定，如 3~8 分钟）、每小时提交上限、定时启动
- **自动下载**：完成后自动下载 MP4（也可手动点下载）
- 队列与图片本地持久化（localStorage + IndexedDB），关页后重开自动续跑；失败任务一键重试（清掉旧造型走完整预审，审核/渲染失败都能干净重跑）

**接口链路**
- 建组（第一张）：`avatar_group/photo/temp.create` → PUT S3 → `photo/temp.convert` → `group_id`（主 look 的 `look_id` == `group_id`）
- 追加造型（其余张）：`photo/temp.convert?…&group_id=<组>`，把每张图作为新 look 加入同一组（新 `look_id` 由 `look.list` 比对认领）
- 审核状态：轮询 `GET /v2/avatar_group/look.list?group_id=…`，逐 look 读 `status`（pending→completed）与 `moderation_msg`
- 提交渲染：`POST /v2/avatar/shortcut/submit`，`avatar_id` 传**目标 `look_id`**（按指定造型出片）+ `use_unlimited_mode:true` + `source_type:"avatar_video_shortcut_modal"`，返回 `video_id`
- 轮询 `pacific/video.get` 至 `completed` 后取签名 `video_url` 下载
- 轮询节奏：审核每 30s（超时 180s）；渲染进度首轮 30 分钟、之后每 10 分钟
- ⚠ 勿走 AI Studio 的 `text_draft.generate` 做整片生成：会被标记 `low_priority` + 未付费，月额度用尽时永远排不上队

**注意**
- 提交与轮询运行在页面内：需保持任意一个 HeyGen 标签页开启
- Avatar Shots 通道有**每日生成数量上限**，超出后服务端直接拒绝（任务显示失败原因，次日重试即可）——建议用「每小时上限」控制节奏

## 技术说明

- **Manifest V3**，Content Script 注入，无后台常驻进程（Background Service Worker 仅在下载时按需唤起）
- 所有 API 调用均使用 HeyGen 页面自身的 Session Cookie（`credentials: include`），无需单独登录或填写 API Key
- 声音预览通过 `POST /v2/online/voice.stream_preview` 获取 NDJSON 流，客户端解码 base64 音频块后拼合为 MP3 Blob 播放/下载
- 「找我的视频」通过 `/v1/projects` 和 `/v1/project/items` 只读扫描团队空间，需携带 `x-space-id`，再在客户端按创建者 `username` 过滤
- 本地数据库存储在 `localStorage`，Key 为 `hvt_db`

## 版本记录

### v1.21.0
- **换声音大幅提速：从数十秒降到 1～2 秒**。此前每次切换都要在 HeyGen 原生弹窗里"翻页找人"——198 条声音要点 10 次「查看更多」，实测单标签页约 47 秒、跨标签页 130 秒以上。现在改为**优先直接复用本地缓存的声音对象**完成切换（插件后台早已缓存全部声音），只有缓存里没有时才退回原来的慢速查找。
  - 依据：实测确认缓存对象与弹窗内部对象**字段完全一致**，切换后确认按钮正常激活，所以直连是安全的。原有的"点确认 + 等弹窗真正关闭"防假成功校验**原样保留**，没生效仍会如实报失败。
- **修复 My Avatars 头像详情页换声音完全不可用**：顶部声音下拉是 Radix 菜单，插件用的合成点击打不开它（`aria-expanded` 一直是 false），整条路径直接报"未找到声音入口"。改用带 `pointerdown` 的点击方式后恢复正常。
- **修复切换失败时看不到失败原因**：失败提示那行引用了一个早已被删除的变量，严格模式下会抛异常，导致状态永远停在"正在切换声音…"。
- **「查看更多」展开不再死等**：改为等列表真的加载出新行就继续（实测每次约 1 秒，此前固定等 3.4 秒），并加了总时长上限防空转。
- **弹窗搜索失败后会恢复列表**：HeyGen 原生搜索是服务端匹配，实测**会漏声音**（部分英文名声音搜索结果为 0），且搜不到时会把已加载的列表清空；现在会等列表恢复后再继续，避免展开进度白白丢失。
- **搜索更快**：粘贴完整 Voice ID 且本地已命中时，不再多余地全量扫描一遍；同时用服务端搜索先探一次快速出结果，但仍保留全量扫描兜底（因为服务端搜索不可靠）。

### v1.20.8
- **彻底修复"换回 Avatar III 引擎"在各页面（尤其 Avatar Shots）失败/间歇失败**。本次修掉了这条链路上多个叠加的根因：
  - **打开下拉的奇偶翻转**：改为职责拆分——content.js 只负责打开下拉（合成 pointerClick，且仅在菜单未开时点一次，绝不重复 toggle），桥接只负责在已打开的菜单里选中 III；不再由桥接对触发按钮过度灌事件。
  - **英文界面识别不到菜单**：引擎正则尾部的 `\b` 词边界在"选项名+英文描述无空格拼接"（如 `Avatar IVGeneric…`）时失效，导致 III/IV/V 全部匹配失败。去掉尾部 `\b`（仍能正确区分）。
  - **选中不生效**：Avatar Shots 的菜单项不是标准 Radix `menuitem`。改为由 content.js 定位并打标记、桥接直接激活该元素，并在调 React onClick 之外补一套会冒泡的原生指针序列（经 React 事件委托触发），覆盖不同页面的菜单实现。
  - **误标记页面诱饵**：`findEnginePopup` 选择器里的 `body > div` 会把含 "Avatar IV/III" 文本的整块页面容器（含历史视频卡片诱饵）误当下拉。删除 `body > div`，只认真正弹层。
  - 其余：`findDowngradeButton` 只认可见且带 `aria-haspopup="menu"` 的真触发器；弹层可见性判断改用 rect 尺寸（兼容 `position:fixed` portal）。

### v1.20.0
- **换声音/引擎降级不再依赖写死的页面路由**：此前靠 `/avatar/`、`/create-v4/` 路径白名单判断"当前页面能不能用"，HeyGen 改版换路由就会误判成不可用（语音按钮明明在页面上却提示"请到 XX 页面"）。改为**探测页面上真实的入口控件**（Avatar Shots 的 `#audio` 语音按钮 / My Avatars 下拉 / AI Studio 语音行 / Switch 按钮 / Avatar IV·V 引擎按钮），路由与样式改版都不再影响可用性判断
- **无入口时给一键跳转**：不在编辑器页面（如首页）打开换声音面板时，直接显示「→ 打开 Avatar Shots 编辑器」按钮，一键跳到自带语音控件的编辑器，解决"用户不知道编辑器链接、切不过去"的问题

### v1.19.0
- **运行中导入新批次会主动询问**：流水线运行时添加任务，弹框问「立即加入队列」还是「先检查，稍后加入」（默认后者）。选「立即加入」无需停止流水线即可并入当前队列；此前新批次一律静默暂停，只有一条 6 秒 toast 提示，容易被忽略导致以为"第二组没生成"
- **新增「已暂停」常驻提示条**：队列区顶部显示暂停任务数与 `▶ 恢复全部 N 条` 按钮，运行中同样可点，不必再逐条点行内 ▶ 或先停流水线

### v1.18.0
